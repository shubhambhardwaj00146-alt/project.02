# CareerPath-ML: Campus Placement Package Estimator

## 🚀 Project Context & Overview
Developed as a B.Tech CSAIML Semester 1 project, this repository implements a Supervised Machine Learning regression framework to dynamically estimate a student's final campus placement salary package (calculated in Lakhs Per Annum - LPA). Building predictive talent analytics simulators mirrors machine learning engines used by EdTech companies, modern university portals, and corporate talent acquisition cells to evaluate student engineering profiles.

## 🛠️ Software Stack
* **Language Stack:** Python 3
* **Algorithmic Library:** scikit-learn
* **Data Engineering Blocks:** Pandas

## 📊 Feature Matrix Architecture
The regression engine evaluates final salary compensation packages based on these foundational academic and technical metrics:
* **CGPA:** Cumulative Grade Point Average, representing overall academic consistency (Continuous)
* **Coding_Rating:** Standardized programming metric tracking algorithm accuracy on portals like HackerRank/LeetCode (Continuous)
* **Internships_Done:** Total count of hands-on corporate tech roles completed (Quantitative)
* **Target Variable:** 'Package_LPA' (Predicted Salary in Lakhs Per Annum)
